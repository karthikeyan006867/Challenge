# Build the Future with AI — From Code to No-Code

## About the challenge
Welcome to **Build the Future with AI — From Code to No-Code**, a global student-led hackathon designed to empower innovators to solve real-world problems using AI, web technologies, and no-code tools.

This hackathon is built for **all skill levels** — whether you're a developer, designer, or beginner exploring no-code platforms.

- 🌍 Open to students worldwide  
- ⚡ Build impactful, real-world solutions  
- 🧠 Learn, innovate, and showcase your skills

## Requirements
### What to Build
Build a project that solves a **real-world problem** using one or more of the following:

- 🤖 AI / Machine Learning
- 🌐 Web Development
- ⚡ Low / No-Code Tools

Your solution should be:
- Practical and usable
- Innovative and creative
- Clearly focused on solving a real problem

You can work individually or in teams.

### What to Submit
Your project must include:

- 🎥 Demo video (2–3 minutes)
- 🔗 Project link (live or prototype)
- 📁 GitHub repository
- 📝 Clear problem and solution explanation
